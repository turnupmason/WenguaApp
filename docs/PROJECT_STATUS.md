## 当前风险和未决

- 用户可能只在聊天中提供章节原文，云端 GitHub 无法自动保留书籍的版权正文。要避免跨对话需要原文字节却没存储的情况，用户可在自己的电脑 `local/books/` 按章备份。新对话仍可以仅靠公共 GitHub **继续已经提交的抽象知识**；如需精确复核原文，则必须有实际章节文件。
- 盘式的 1080 状态索引 ≠ 1080 张有来源核验的完整盘；后续由起盘章节逐步验证。
- 不保证不同流派全部断法相同；V1 只做时家转盘。
- Web 资料可辅助调查，但不得代替二书原文。
- 正式 App 必须等待专业规则、盘面与解释链达到审核条件。
- 用户准备开始逐章输入；**现在无待处理的新增章节正文**。
