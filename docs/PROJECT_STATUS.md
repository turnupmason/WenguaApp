## 第一章已经形成的真实成果

原书输入：用户上传 `神奇之门_时家奇门的起局方法.txt`，UTF-8 26691字节、191行。
来源 SHA256：`177f6ecba2bf4c165524a48adbdab8fdbd535cdb700dca12b5e5f29b1a75afb2`。
**文本源本次会话已确实读取，不意味着用户 Mac 已经备份到 local/。** 已生成私有 SQLite 文件 `WenguaApp_chapter01_source_only.sqlite3` 供用户下载，本轮不会上传到公开GitHub。

- `data/knowledge/shenqi/shijia_qiju/chapter_manifest.json`：本章来源哈希、完整度、两节索引、术数方法状态和已知缺口。
- `foundation.json`：12条基础与盘面常量；包含九宫、八门、九星、十二地支、六甲、五鼠遁、八神与中五宫寄坤。
- `casting_rules.json`：17项分步起盘方法；标识哪些在明确输入下可以实现、哪些缺精确历法/局法边界。
- `casting_examples.json`：1995-06-11阳遁三局、1995-08-13阴遁八局两张全九宫文字实例；另有阳遁二局值符/值使局部例。
- `src/wengua/casting_shenqi.py`：已知时辰干支+具体局的地、天、门、神盘生成，以及已知日干支/节气的三元定局、五鼠遁、旬首。**输出仅 `source_text_consistency_only`，不越权标记引擎正式已验证。**
- `tests/test_casting_shenqi_chapter01.py`：来源中全部9宫字段的文本逐宫测试；`tests/test_chapter01_knowledge_ingest.py`：本章32条元数据的幂等SQLite登记和私有原文SHA保护。
- `schema/migrations/001_chapter_knowledge.sql`、`src/wengua/chapter_ingest.py` 和 `scripts/import_casting_chapter01.py`：可将12+17+3条公开抽象资料装入个人本地SQLite。
- `docs/CHAPTER_LEDGER.md`：详细本章工作日志与阶段边界。
