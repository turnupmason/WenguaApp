## 与之前三章的可调用关系

`第一章九宫事实` → `第四章符号与九星/八门属性` → `第五章干干、门门、门仪与格局` → `第六章问事人/关系取用→横向纵向证据→时令/主客/反证→应期条件`。

概念键复用 `trigram:乾`、`door:开`、`star:天芮星` 等；第六章增加 `role:...`、`principle:...`、`timing:...`、`constraint:five_no_encounter:...`。直接把真实场景按主语/关系映射，不得误把用户代朋友问当朋友就是日干，也不能给非本人健康问题无条件套本人主用神。

- `日干`首先对应**起问人**；若问父母，一般参看`年干`；若问孩子，参看`时干`；同事兄弟参看`月干`；附加乾/坤/艮/兑等视父母及性别/年龄而定，不能无事实硬推。
- 星/门/神、年月日时、年命可能是多重用神，不是“按一个领域只给一个固定符号”。
- 横看日干和时干互相比时，根据二者**落宫之五行**；竖看同一宫的星与宫、门与宫、天盘干与地盘干。跨宫组合和同宫克应必须区分。
- `阳遁`以内宫1/8/3/4视近快；`阴遁`以内宫9/2/7/6视近快；中五宫原书未列入内外分区，需保持unknown。
- 问事重大额外看九星，不得机械视作必吉/必凶。
- 原书还明确提醒：在整体判断中**中平、吉中有凶与凶中有吉**；不能见凶格就吓唬用户，也不能宣称灵验率获得科学证实。

## 关于1080与8640：数据库计数单位修正

- `1080 = 阴阳2 × 九局9 × 六十甲子时60` 是当前项目采取的**局态索引键数量**（尚未证明1080键都对应不同的完整盘面，也未排除真实排盘变体的状态差异）。
- `8640 = 八个外宫 × 1080个局态键` 是第五章引用的八宫**宫位组合条目**数；`9720 = 九宫 × 1080` 是九宫统计口径。
- `8640/1080=8` **不证明每张完整盘在一年里重复出现8次**；8640-1080=7560不能称“7560张重复的完整盘”。
- 用户提出的一年360天、72候、4320个时辰的理想化推导是另一种历法建模问题：`72/9=8` 不能套到**阴阳各九局（共18局）**的每个局上；如果各分布均匀，`72/18=4`，且这也非古籍印证的全年均匀定局/完全盘面重复证明。
- 真正去重应在**指定流派方法版本、完整输入和盘面属性**下对每张生成并复核的盘计算 canonical JSON / SHA256，然后统计相同输出，不提前声称唯一1080或重复7560。
