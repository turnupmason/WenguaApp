# WenguaApp 婚姻22场景 V1.8：无年命的作者式取用与综合断案

## 本轮修正

**年命不是必填参数。** 人物没提供出生年时，不补造年份、不把当下问事年干当成年命，也不因此停止整个婚姻问题。依《神奇之门》婚姻预测方法及《开悟之门》婚姻实例，先辨自测/代测、具体问事事件，按真实起盘的乙奇、庚金、六合、日干、时干及其他门星神格关系取用。年命有则作作者条件化补充，没有就跳过年命本身。

## 用神判断路由

1. **both_years**：双方真实出生年命已知，在原V1.7 27条多因素规则中取用，乙庚六合等照样是条件候选，不仅看年命一项。
2. **one_year_optional**：一方年命已知，结合该方年命与六合；另一方没有年命则以原著传统象征和日时干问事关系分析，绝不能把对方时干或乙庚单纯当真实特定个人。
3. **no_year_optional**：两方均未提供出生年，按乙庚宫传统婚姻关系、六合与乙庚之间双向生克、日干与时干问事关系，以及六仪击刑、三奇入墓、门迫、真实反吟等组合反证。不同类象大致一致才能形成有倾向性的**传统成败候选**；出现矛盾应标为mixed，后续就不能编应期。

对于同性/不限定性别或对象身份不明确的事件，乙庚只表示古籍中的**传统婚恋符号关系**，不能假定两个真人一男一女，更不能断某人的真实心理、性取向、私生活、家暴、传染病、违法或官司归属。关系是否健康应同时依据现实行为而非盘象标签。

**应期顺序**：先判问事的目标事件、检验实际主辅用神、综合反证和作者错误案例，后按真的盘面旬空与《开悟》20条条件化应期法挑选符合的分支，太阳黄经算法换算为有起止的节气月窗口。没有空亡触发条件则不硬套“填实/冲实”；没有充分支持则不强行给具体日期。现在是可复核研究结果而非正式全24项、独立精确应期预测成品，GPT自然200字断语仍不批准。

## 命令行使用方法

在项目根目录使用**已经有起盘引擎生成、九宫逐字段可复核**的完整JSON（包括`chart`、`calendar_inputs`和`inquiry`），其中`inquiry`可以只包含领域、具体场景、问题和关系，不必包含双方年命。

```bash
python -m scripts.run_marriage_judgment_v18 \
  --input your_chart_and_question.json \
  --database 'archives/sqlite/WenguaApp_双书194案例_婚姻无年命作者取用方法V1_8_完整研究库.sqlite3' \
  --output no_birth_year_author_audit.json
```

该脚本不覆盖原始完整SQLite，输出按阶段呈现`year_role_binding.strategy`、`evidence_decision.support/counter`、原著对应SHA和行号、已计算的格局及适用应期。如果只有`inquiry`且没有提供出生年，仍可进入`no_year_optional`。完整天文年/月/日/时仍是**起盘时间信息**，不能被误解成问事人出生年命。
