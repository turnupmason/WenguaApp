## 通用规则：8条来源行对应一组领域取用

- 第5行：日干本人/行人、出行方向宫位与其生克、吉格吉门；时干空亡、墓绝及年命等都须综合。
- 第7行：乘车景门为道路、伤门为车辆；格局、水灾与盗贼是原书传统象意。
- 第9行：水上休门水路、伤门船只，青龙逃走/白虎猖狂等条件仅用于古籍研究。
- 第11行：飞机九天航线、开门飞机；同时检验门星宫格。
- 第13行：日干时干在内盘外盘的出发远近、开门下临地盘干为启程应期。
- 第15行：未出发推归期，以出行日干宫下临地盘干为归期。
- 第17行：人在外以本人用神和年命门、星、宫、神、时令判断。
- 第19行：庚格的阴阳日上下干推归期，乙庚合/庚墓空不成格；行人天蓬/天芮远近辅助及伏吟反吟，必须在语境中有条件调用。
