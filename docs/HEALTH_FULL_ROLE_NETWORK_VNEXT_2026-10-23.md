# 疾病专题完整用神／星门神干／乾坤关系网（2026-10-23）

**状态：仅 V-next 独立审阅入口已实现，不替换 V3.9.1 正式断词，也不将古籍传统象意视为可证实的临床判断。** 用户最新要求：断病不能只比天芮和天心；患者用神、实际年命、乾坤、乙奇、时干及相关宫内全部星、门、神、天地盘干都需计算各自的实际月令、落宫关系、宫力、空墓刑迫，再判断真正的生克作用能力。

## 一、先算全盘相关宫，不准漏掉乾坤

1. 全盘宏观：九星/八门伏吟反吟，取原书有源的动静和缓急象，不替换病吉凶条件。
2. **天芮病宫**（星本体九星月令旺相休囚废×对宫五行关系、宫本身月令旺相休囚死；原有天芮25格复合象意仍每盘只有一个事实）。
3. **天心医生宫**：独立查月令、星自身强度、宫力、星门神和所有天地干的强弱，之后与病宫双侧比较。
4. **乙奇医药宫**：乙按天干五行五态及实际落宫来查，并保留天/地两盘十二长生、墓、刑、空、门迫；与天芮及患者宫对照。此处「乙奇」只指传统用神，不能据此给出加药/停药建议。
5. **患者用神宫**：必须先调用现有 `bind_patient` 的具体本人/夫妻/父母/晚辈取用；不能见日干一律认本人。本人与代测按原书资料可核角色取用，再和病宫、天心、乙奇、时干等比较。
6. **患者真实出生年命宫**：只有用户给出完整合法生年干支、既有起盘引擎确实能定位该干落宫时才启用；年命没有给、甲遁干未核得时返回“缺失、不得虚构”。绝对不得用问测年份冒充患者年命。
7. **时干事体落宫**：独立查干五态、宫月令、宫内星门神、双盘长生、空刑墓迫、与病宫及患者宫双向关系；时干“旺”单独不算吉证。
8. **乾六宫、坤二宫：无论问病人性别、亲属关系是否提供，每一张真实九宫都必须检查**：实际该宫星门神、所有天盘星携干和地盘干、各符号月令／符号对宫关系／五档假说强度、宫月令、双盘长生、空亡与阻碍。**但盘面存在不等于具备患者身份**。只在 `bind_patient.extra_cells` 有来源指定时标记源人物宫；用户实际指定性别对应男乾/女坤但没有原书角色绑定时只标“性别参考候选”；性别未提供则仅“独立盘宫观察”。两宫都要纳入关系网，不能仅算符合性别的一个，更不能把两宫都直接算成人身吉凶。
9. **其它实际已由原书人物档案绑定的辅助宫**：如有，则保留记录并参与对照；同一真实宫被“患者”“年命”“乾宫”等多个角色引用时不重复生成独立物理吉凶票。

## 二、角色间的完整两层交叉计算

`src/wengua/health_full_role_network_vnext.py` 公开两种层次的只读研究审计：

- **全方向角色关系网**：真实存在的 `illness / doctor / medicine / patient / natal(可选) / hour / qian / kun / extra` 每两个角色双向配对。先查各角色的关键用神对应**20格主关系＋第五种物理关系兜底**，再经预先生成的20×20或25×25交叉查表，以及施力方／受力方两个宫自己的月令旺衰、实际宫生克和阻碍决定传统作用候选。每条含实际 `actor/target/fact_id/physical_pair_id/role_status`；同宫只可称同宫，不强造宫克。重复物理宫位关系标记 `same_physical_pair_already_seen`，不能多投票。
- **与病宫、患者宫的逐层交叉**：对每个关键角色（天心、乙奇、时干、年命如有、乾、坤、其它辅助），把其实际宫内**八神、八门、全部天星、所有天盘携干、地盘干**分别与病宫、患者宫同类及跨类每个符号作两两组合，独立存 `all_cross_layer_factor_pairs`；每条记录两个不同物理层的事实ID、各自五档、宫力、两宫五行关系、强弱是否足以触发传统“能／不能／艰难／条件待核”。**不能遗漏八神本身无月令**这一特殊规定；值符按土；星废、干门死不能混用；天盘干与地盘干各自留 ID；中五没有常规神门星不能凭空造出来。
- **角色相关性严格受控**：`role_status` 标明按书已绑定、性别候选、纯宫观察、年命缺失。审阅级矩阵等级即使“极大”也只是研究标签，不自动纳入吉凶票；真假空、击刑、墓、门迫、冲合、格局、应期仍需逐项古籍条件复核。

## 三、简洁的自然中文断案模板

> 【总局】九星/八门伏反吟（情况），传统缓急（候选）。
>
> 【病】天芮（五态）×落宫关系（四主/第五例外），星力（五档），宫位月令（状态）与宫力（五档），空墓刑迫（真实事实及未知）。
>
> 【医药】天心星、乙奇分别按星/干自身20格查，再和病宫及患者宫作跨层比较（五行克/生/被克/被生/比和/同宫，克得动／克不动／艰难／限制待核）。
>
> 【患者】根据具体问测关系选用患者宫及**用户真实提供才使用的年命**。逐宫全符号查表，分别和病、医、药、时干比较；列证据和反证。
>
> 【乾坤及时干】乾六、坤二**都**实际计算，先描述真实五行力量及全宫符号，再指出符合的角色来源或“仅观察”；真实时干一并查。各自对病宫、患者宫的方向和可能效力明确写出。
>
> 【结论与应期】按专题作者独立证据链去重、考虑主次与反证，最后输出传统倾向或“暂不能定”；无真实触发条件绝不捏造时间，不给治疗方案。

此模板仅在 `health_palace_sequence_vnext.py:format_sequence_sections` 增加“年命、时干与乾坤全宫力量”一段；实际数据另外由 `health_severity_vnext_review.py` 和 `health_text_pipeline_vnext_review.py` 暴露 `full_health_role_strength_network`。V3.9.1 正式入口及原生 SwiftUI 发布路线不变。
