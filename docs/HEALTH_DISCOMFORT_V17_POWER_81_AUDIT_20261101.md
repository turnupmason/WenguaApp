# V17 病位力量及81格审计 · 2026-11-01
本次只更新独立 health.discomfort，V8.0 病情轻重规则、200格资源、81格资源、±5评分与十档结论全部不变。
## 复现与纠正
V16 客户断语残留“涉及不同身体区域的分别列明，不把每个器官都说成同一个位置”等冗长解释；独立符号只有落宫事实、缺少真实强弱。新 V17 删除该句，并分别取病星、天禽、两星携干、地盘干、宫门神、患者用神、伤门和时干的源力。不可用 V8 落宫吉凶净分的绝对值作为五档强弱。
## 已使用的两种源数据
1. data/mobile/health_vnext/health_energy_200.json 共8张25格：星按月令及宫关系、门按月令及门迫、天干按十二长生和月令；八神只按本神五行对宫关系，绝不加月令或借驻星力。Swift 复用 WenguaNativeEnergyBundle 和 WenguaVNextEngine.factor / godTiers，不编一套新分档。真实的每一符号单独取力。同字天地干仍须按自身位置与长生独立读取。
2. data/knowledge/health_81_excel_20261025/81_pairs.tsv 共81个真实天加地格。病星实际携干加病宫地干读取一格；天禽同宫则按真实中五寄干另取一格，不能重复计物理宫基础分。81格吉凶不是五档力量，不得直接映射疼痛强度。
## 限制与主次
源5档 极小/小/中等/大/极大，弱病星或弱伤门的传统象意解释降低优先级。病宫真假空依实际驿马、冲空、月令判别；墓、刑、门迫等是真实条件，不虚构奖励。大吉神等正向力量不直接代表痛感，反向凶象大也无法证明现实疼痛更剧烈。每次只显示古籍文化象意，不给出真实病位或疼痛强度医学断言。
