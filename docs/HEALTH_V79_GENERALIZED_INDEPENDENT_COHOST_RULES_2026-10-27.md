# V7.9 通用计分去重与独立同宫条件规范（2026-10-27）

这是用户从 V7.8 两个固定盘的审计总结出的**通用算法规则**，不是给已知两盘“调成正确答案”，也不是原书新增案例或临床判断。V7.8 源码/结论依 Git 历史和原归档可回放；V3.9.1、200格能量源、81格规则源及原43章194古籍历史案不可覆盖。

## 1. 一宫一次基础分：格局已含天盘干能量

- 根据真实领域与关系选本次用神（天芮、天心、乙奇、时干、患者本人、值符、已知年命；只有真实长辈选乾/坤）。
- 按每个**不同物理宫**，对驻宫星/门/神/实际有序天地格各求一次真实分，相关墓/刑/门破/真/假空按现有顺序处理。一个宫不会因多个用神角色共宫而反复产生基础分。
- 81天地格分档已经使用真实天盘干能量和生命周期；**不得另外把同一天盘乙/丁/庚的自身能量加到宫内总分**。地盘干也不另作为第二个票。角色本身的200格源能量可独立保留**诊断/关系/条件门槛数据**，不能转为叠加票。
- 固定原脚本、角色名变化、同宫多个角色、甚至同一角色兼任多个名字，都不能更改该宫已经计算的基础分。

## 2. 必须是另外一个实际用神“临”独立吉助符号

将物理宫和真正的**符号身份**区分。符号身份最少包含 `kind`（stem/star/deity）及其原名。每一物理宫选择的合法宿主来自：天芮病星、患者／关系本人、时干、真实已提供的年命、仅真实长辈的乾坤辅助；前面完全独立的天心医生和乙奇医药是可供其他角色临宫的客体，但**不得以“医生天心自己临天心／医药乙自己临乙”作为加分宿主**。

给某个候选吉助符号 `X` 加分之前，必须存在同宫实际选中的宿主 `Y` 且 `Y.kind/Y.symbol != X.kind/X.symbol`。同宫多次引用 `Y` 不能重复数，乙在时干/年命/乙奇三种名字同时出现仍是一枚乙。

- 时干乙单独临天盘乙或地盘乙（没有其他不同宿主）：乙奇条件+0；时干丁自己临丁同理。
- 同一宫另有天芮星（不同于乙）时，乙奇可以触发一次；同宫另有时干戊、患者己或年命庚时亦然。
- 时干戊临天心星：天心特殊+3，若天心能量极小则+2。
- 时干戊临值符：值符特殊+3，若值符受宫克则+2。
- **时干戊同时临天心和值符**：二者是不同真实符号，分别触发，常态为+3+3=+6；同宫逢空，(3+3)//2=+3。
- 时干戊同时临乙丁同宫、天心、值符：乙丁是一组只取符合条件的最高一档，另外天心与值符分别算；常态3+3+3=+9，同宫逢空 `floor(9/2)=4`。宫内有更多用神角色亦不得乘上其数量。
- 天芮与乙、丁、天心、值符同宫也采取相同通用算法；并非只给本轮两个盘建条件。
- 乙和丁自身的两枚不同候选若落同宫，依用户规则仍归**一组奇助**，不做+3+3。

## 3. 实际能量和限制

- 乙/丁正常力量极大、大、中、小：奇助+3；极小：+2；此实际干入墓或击刑（不论一个或两个同时存在）：限制优先，只给+1。
- 地盘乙/丁须有真实十二长生落位、实际源力量及此前确认的五种强位；无事实不可臆测+3。墓刑必须精确匹配被限制的那一干。
- 值符正常+3，被本宫克则+2；不能以“值符角色同时存在”再重复加同一个值符。
- 天心正常+3，能量极小+2；若自身物理宫逢空，不单独先取“天心+1”再跟其他候选重复半减，而是将此宫所有符合条件的独立特殊吉助**求和之后一次整除2向下取整**。当天心单独极小+2且逢空，结果自然为+1。
- 基础宫位分可为负数，但不能因此取消真实已验证的独立同宫条件；也不能把“综合宫吉凶的绝对值”直接当成跨宫克制强弱。

## 4. 独立跨宫作用与全局项

跨宫克病关系、极弱病星的真实外泄、五不遇时各独立实宫-2、伏吟慢/反吟快仍属于另一层。不允许用一宫的“乙/丁/天心/值符临”加分作为另一宫又一次克病加分。V7.8 以 `abs(施力宫最终吉凶)>1` 判断克病能力以及 5×5 资格门槛旁路的疑点**尚未解决**，不能把 V7.9 同宫去重误称为所有计分问题已验收。
