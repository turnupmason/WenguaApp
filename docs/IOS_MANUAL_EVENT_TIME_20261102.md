# 当前问事／事项择时与候选组 · p4 · 2026-11-02

用户明确手动时辰的意义：为旅游出发、约会、婚礼、手术等已有计划，选择事项将发生的时刻排盘；普通产生问事念头则用当下确认时刻。用户另确认多个候选合为一组，一次静心，15天只登记该组。并非按任意过去时间反复测同一病情，也未授权为迎合选日结果改封存评分。

## 已接入的实际流程

1. 已支持健康主题的填写页增加“当前时辰问事／事项时辰择时”。当前模式在完整30秒后最终确认时才捕获一次真实手机时间和本机IANA时区。
2. 择时模式以中文公历滚轮输入年月日时分，选择事项发生地时区，1至6个候选。保留每个真实瞬间的UTC偏移，不把用户选的未来时刻换成现在。
3. 同一组候选全部真实计算成功、断词成功后，先用一个编码值保存整组，再登记一次15天限制。任何一个时辰失败，整组不保存也不登记；不会用旧盘、跳过失败候选或补成好看的时辰。
4. 结果页可切换比较候选的实际日期、四柱九宫与等级；历史读取旧单条和新整组格式，并可在同组中切换。保存实际确认时间，未来事项时刻独立保留，限制不会错误推迟到未来再开始。
5. 新的“挑日子 · 按事项时间排盘”入口提供旅游、约会、结婚、手术、其它计划事项的真实九宫。该工具不是已通过专题占断验收的第三个领域，不启用疾病用神/吉凶。

## 首页“此时辰”的严格范围

- 手动健康轻重：读取该时辰实际V9计分/V11原文等级，显示“此时辰：中吉/大吉/极大吉/……”。不是把宫位力量当吉凶，也不重新计分。
- 手动奇门论疾：V27病位原始各节逐字保留；另对同一时辰、同一人物实际调用封存健康轻重接口，只将健康盘象等级投影到首页。专业解盘另可展开原样的等级依据；不会把V27部位推断或任意别盘转成等级。
- 只有真实同ISO健康轻重原文能提供健康等级；当前时辰问事不新增此“择时”标签。所有首页和历史标注选中日期/时间/偏移及时区，不暗称未来某时辰就是“今天全天”的运气。
- 旅游、约会、婚礼、手术专项择时规则尚未验收，当前显示“此时辰：吉凶待核”，只提供真实排盘。不能借健康分数排列这些事项，也不能把疾病盘象等级说成现实手术更安全、医生技术更好或药效更好。
