# 来源、用神、解词审核流程

1. 逐章存原书，不删除细节；记录书/章/版本/sha256。
2. 案例以 event_family_id 去重，分离初始问事条件、作者选择用神与证据、作者原判断、后来反馈。复述原书答案不算盲测。
3. GPT 可以在研发阶段查外网、比较古籍方法和起草「待审断词」；网络搜索只能作外部背景来源，不得假称用户原书原文，亦不得自动升级成已验证内容。
4. 每条规则要包含流派、问事领域、代测关系、条件、宫位/门星神事实、适用例外、原书证据范围、审校状态与编译版本。没有规则时拒绝生成断语。
5. 与作者案例对照时分三项：盘面计算与事实；作者方法与用神条件；传统预测与真实反馈，不把三者混成所谓准确率。
6. 1080索引只是待填盘面空间，不假设局×领域就能预测任何人任何事。正式报告必须能复述取用、证据、限制和引用。
7. 新增古籍只增量加源、规则与版本；保留历史结果供回归，不强行追求全部判断一致。不同古籍冲突要显示来源分歧。
