# 两书独立 RAG 验收

代码和来源合同见[使用说明](../../WENGUA_TWO_BOOK_RAG_20261105.md)。本目录只存软件日志、计数、哈希和检查证明；原文、逐题检索黄金范围、Excel与HTML在私有加密来源包。

- `preservation_proof.json`：753份既有受保护文件、49份V5.1运行合同哈希及原双书库保持不变。未删除、合并或改写原有起盘算法。
- `coverage.json`：43章全文、194案、1,008原索引分析、1,451材料处置和每个非空行覆盖。
- `retrieval_audit.json`：46个有针对性的来源检索检查，非盲测、非模型或现实预测准确率。原始问题和完整证据仅在私有包。
- `prompt_budget_audit.json`：官方8B tokenizer检查52份提示，不加载LLM/GPU，不截断共同条件、问题或程序盘。
- `rag_excel_audit.json`：实际保存并重新读取119,002格。
- `tiny_bridge.json`、`tiny_release.log.gz`：实际微型Qwen+PEFT CPU检索/生成/相同提示基模对照；验证权重和原训练合同未变。不能据此声称真实8B/CUDA效果已测。
- `delivery_verification.json`：实际来源ZIP的认证解密及15个文件哈希核对，口令未公开。另由Windows CI用非书软件夹具检查内置.NET路径。
- `full_run/`：完整测试发现、所有既有断言和原有跳过状态；不删失败、不增加跳过。
- `remote_source_ci.json`及相应压缩日志：提交后真实同源码远端工作结果。

过程保留了首次检索检查中的两条黄金坐标修订，以及真实检索缺陷修复（有向天/地盘干对、失物口语提示）；未把失败消失当成原来就通过。A/B对照段超出单案物理范围的首轮构建拒绝，改用原书明确比较关系逐项核对后关联两个原事件，未放宽所有案例来源闸门。原始逐题/构建失败现场保留于私有工作区。HTML首轮数字版本拼接错误、最终修正及Excel读回记录亦保留；所有检查结论以最终源码实测为准。
