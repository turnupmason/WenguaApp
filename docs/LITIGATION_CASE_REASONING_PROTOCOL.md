## 第一节先建立领域方法

取用优先级根据原书第5–15行：值符代表原告，天乙（**值符落宫地盘之星**）代表被告；开门法官、六合证据或证人、景门诉状、丁奇传票、惊门律师。本人/亲属或代问他人时额外参考年、月、日干及关系而不是把乙奇固定当被告。必须组合原被告宫的旺衰和生克、开门法官宫、景门诉状与六合证据的旺相/空亡、刑事拘禁疑问的甲午辛与壬癸等、应期以及反证。结论都应显示使用前提、文献出处、未被证明的条件。

## 六个来源事件，禁止拆案和倒灌

1. **父亲受检察院传讯（原书19–59行）**：女儿问父亲，先取年干乙，再连看庚与景门举报信及开门检察院宫；第54行原书用地盘乙及丙己和内外盘给己日释放，后来第56、58行是反馈。作者认定诬告不能成为现代法律事实证明。
2. **同事拘留（60–92行）**：月干戊代表同事，另以甲午辛作为罪人辅助，比较天蓬、法官开门与多宫生克；第87和89行为破财金额与释放月份推导，原书第91行再披露后果。不能将最后交出的款项倒填入最初已知事实。
3. **房产调解（93–133行）**：已有多次早期占测的叙述，但**没有另外印出前次九宫**，不得补造。值符宫原告、天乙宫被告，开门法院偏向与六合景门证据逢空是相互冲突的线索；第130行现场方位建议、132行调解及搬迁属于原案后续，非新独立预测。
4. **是否实刑或缓刑（134–178行）**：原书按法官开门入墓、被告宫下临辛、乙辛格反证以及诉状缺证、律师惊门宫比较判断；第173–177行才透露真正开庭、民事赔付、缓刑结果。文献断刑不能代替律师或法院。
5. **学员误用乙奇（179–223行）**：最关键教学负例。原学生第214行明说“乙奇为被告”，张志春第220行反驳此方法，第222行改用“值符落宫地盘之星——天乙”综合复盘。第218行书内说欠款追回，故**结局书内默认成功**与**方法明确错误、不得正向训练**必须分别登记。`historical_case_reasoning_corrections` 专门保存两条作者批评及第4组错误步骤。
6. **劳动仲裁（224–267行）**：第228行同一段含**事前问事事实与已经说出的首次断语**；`known_before` 严格裁切在首次断语之前。第230、232行其后才知悉完整处分详情，236、238行先叙述了最后撤诉结果；真正原盘在245行，解释写在263和267行。两组因果解释只能标**原书结果后呈现的复盘解释**，不准当盲测期间已存在的事前独立推演。第263行明确“五宫中的壬也寄于坤二宫”，对中宫处理与旧起局规则一致。
