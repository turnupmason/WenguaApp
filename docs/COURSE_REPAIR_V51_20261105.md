## 来源和语义发现

1. 已较稳定：五道简单星位读取题，基模本来就正确；微调主要缩短措辞。给定“马星当令或被冲”的条件题保持正确，不能泛化成完整应期能力通过。
2. 仍不稳定：河图金数与后天宫数混淆；有序干格名；动静占法的方法范围；考试“父母代问→考生本人”多轮条件切换；阴晴、降水、风的区别。r16河图金数三轮均错；天气有epoch越训越差，不能认定再加轮数就能解决。
3. 编辑错误：身份证案整理摘要把“离火红象”错写成“六合红象”。原书离卦火主红色，没有这个错误。旧V5该行在validation，未作为梯度训练行；新版本修正答案及人工复盘笔记，原书文字不改。
4. 输入缺证据：旧chronology/error任务只给背景和盘，却要求复述作者回访、特定日期或纠错。source_ids仅在元数据，不代表模型看到证据；长作者段超过1800字时原来整体未放进输入。“案例库里有”不等于题目可回答。模型编出日期仍是错误，但不能把它不知道未提供的历史反馈算成不会排盘。
5. 评测限制：这些已读题不再是盲题。不能把错误目标、资料不足、专业错误和简单抄盘混算成现实准确率，也不能从低NLL宣称会预测或输出可靠百分比。

完整逐题说明、原目标、实际输入、实际回答、出处原文和逐更新日志在私有发行包Excel/HTML。公开只放聚合统计和曲线。
