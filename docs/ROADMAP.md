# WenguaApp V1 与 V2 的明确边界

V1 核心文献：《神奇之门》《开悟之门》，不等待更多古籍。唯一优先起盘体系：时家转盘，具体排盘方法须从来源文本逐项确认，按方法分别验证。

V1 建设顺序：基础知识和原文入库 → 真实案例分离事前输入/作者步骤/反馈 → 按问事领域和人物关系编制条件化用神规则 → 九宫事实引擎验证 → 通过审查的断词片段 → 全离线手机 App。

传统所谓1080局按十八地盘局与60干支时索引建目录；此索引不等于已经算好或验证完所有完整盘。时区、节气、定局/置闰、日界、排门星神等不能省略。见《神奇之门》相关内容和外部对照材料，但以用户提供的原书为最终验收依据。

V2 再逐本增加古籍及另一流派的独立起盘实现；每条新规则记录来源、条件、审核及内容版本。新增书籍优化断词表达和规则覆盖，不能无依据覆盖原书已有规则，更不能混入其他流派的不同断法。

本仓库为公开仓库：仅上传源码、结构、版本化规则及确认可公开的节录。书籍全文、原始历史案例、个人问事数据默认仅在 local/ 保存（被Git忽略），未经授权不公开。

**当前工程阶段**：初始化；没有两本新提供的原文，没有被认证的盘面，也没有获批的吉凶断语，不应在UI假装已经正确起盘和断案。
