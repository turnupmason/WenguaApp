# 2026-10-28 · 用户实盘截图驱动的九宫定稿（UI Revision 2）

## 用户明确要求

上传参照图以传统九宫盘排布：每宫相同正方形，九宫同时出现；神、星、门、天盘/地盘干仍按原来金木水火土逐元素颜色，内容占据宫格主体。**取消宫内重复的透明「病／被测人」大字和小号墓/刑/角色提示**，以每宫最右侧的深朱砂竖排「病／西医／中医／大吉神／病事／被测人」标识选中用神；同宫按／并列，阅读空间不足可轻触宫详情。原真实天盘、地盘、空/马等信息仍由本机真实九宫与V8只读角色映射取得。中五宫不得补普通星门神。

结果页使用`GeometryReader`按设备当前可视高度预算`min((viewport.width-30)/3,(viewport.height-246)/3)`确定九宫正方形边长并减少大标题/时间框占高；九宫从首屏顶部完整展示，接卦结论仍在盘**下面**，专业解盘及回顶按钮不变。较小机型/系统超大字体可能须实际截图验收，不能仅凭源代码保证所有辅助字号下严格首屏不滚动。

领域屏「请问有什么疑惑？」改为**单行文字**，不加分行符；Welcome「欢迎来到问卦」亦改为单行，正文段落不手动强制断行；两个背景复用静止云层，无 `repeatForever` 动画、`floating` 状态或自动漂移。保留渐显领域卡，这只执行一次用户进入时的过渡，不是循环背景动画。
