## 从定义走向应用

1080物理布局逐个用现有程序重排核对；再用96个实际历法时刻与7种关系情境，计算672份疾病规则教师报告。它们是教学情境，不是672个真实患者或结局观察。七情境包括本人、直接代问父亲、父亲可靠年命、同符号年命别名、朋友、妻子及明确闻讯时刻起局。

672条取用任务用中文说明为何选年干、日干、月干或乙奇，实际藏甲载干与宫位，以及年命是否已知。不把所有“爸爸”问题一律套日干或年干。朋友的父亲首先判断问者关系与起局情境；没有可靠出生资料就不补造年命。

完整生成分析采用当前封存疾病规则的最终模板与档位，不把较早预览字段当现行合断。同宫多用神分别保留符号力量，未知强弱仍标待核；基础宫只计一次。已找到的教学覆盖包括医生与药同宫112情境，其中63情境的两者力量已解且不同，7情境有力量待核；患者与医生同宫75情境；患者与病星同宫、医生在另一宫173情境。它们可能共享盘形，不按独立病例相加。

另有125组现行5×5制约与空亡局部规则练习，以及15组病宫相同的实际历法对照。局部矩阵题明确是抽象练习；实际历法对照可能改变多个盘面条件，不伪称单因素因果实验。真假空亡、墓刑、门迫与伏反吟事实来自现有规则输出，旬空并不自动等于真空。

目前完整生成合断教师的领域是疾病。其它领域已加入有出处的取用切换及原书完整复盘；不声称婚姻、求财、就业等全部新盘综合断语已自动核准。条件改变必须重新分析，最终档位不必强制翻转。

`src/wengua/qwen_application_checks_v3.py` 对给定参考执行引用、字段类型、结构事实及有限最终档位检查。实际9,319条带结构事实的标准答案通过；7类错误变体分别覆盖错取用、补造年命、虚构日期、同宫重复、复制天心力量给乙奇、跨领域错符号和自然结论与证据冲突。缺少机器字段时返回未能判定，不把它自动打成语义错，也不计成功。
