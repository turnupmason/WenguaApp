# 2026-10-23 · 看病严重程度逐宫完整审查与总纲优先（V-next 候选）

> 这是用户指定的 **替换旧片面断案模板** 的最新程序化约束，不修改冻结 V3.9.1、已核时家转盘、Swift/iOS画盘，也不把研究格推断当临床医学结果。旧模板、旧失败CI、43章194历史事件、81天地干格局及源记录继续保留。

## 计算流程（必须按序）

1. **第一步：按真实时辰一次完整起盘**：取得四柱、节气、阴阳遁局、旬首、九宫全部星门神天地干、落宫、旬空、驿马、天盘地盘入墓、击刑、门迫。中五没有普通八神/门/星，严格复用 `casting_shenqi` 和 `solar_chart_clock`；没有起盘源事实就不写断语。
2. **刚起盘即看三项全局条件**（每次都显示）：`health_severity_v27.five_not_encounter(日柱,时柱)` 必须是 **时干克日干且同阴阳** 才为五不遇时：用户规则「主诸事凶」，记**一条全局凶时信号**，不因宫位用神多而重复投票；没命中就明确说没命中。 `health_severity_v25.fuyin_fanyin_facts` 各按外围八星与八门的全盘本位／对宫准确判伏吟、反吟：**伏吟主慢、反吟主快**；“慢快”只表示缓急，不被当作吉凶及某个具体日期。九星门一伏一反时两者并列，不凭“先后顺序”消掉事实。五不遇时主凶是传统象意，不能直接宣称病必死。
3. **领域 + 断事类型 + 人物关系绑定用神**：本模板仅 `health/severity`。按原来源选 **天芮病宫 → 天心医生 → 天盘乙医药 → 实际患者用神 → 时干事体 → 若真实生年命提供则年命 → 实际乾六、坤二辅助观察**，来源模板额外绑到的宫同样审查。不得凭性别同时假定乾坤都是“患者本人”，二宫可作为辅助观察且不能未经原书身份规则独立计票。无年命不造年命；没有真实宫位不强绑。
4. **逐宫统一详查，先病宫再其他宫**：每个选中宫先从完整真实盘取**本宫所有真实九星**（天芮与天禽同宫时两者都读取），按 **九星月令×星自身与落宫关系25格** 精算；八神（值符、六合、太阴、九天四吉；白虎、玄武、螣蛇、九地四凶）只查五行对自身落宫五关系 **被宫生／被宫克／克宫／生宫／比和**，不套月令能量表：被宫生与比和为增强（吉神更吉、凶神更凶）；其余三类为减弱（吉神微吉、凶神微凶），不可把“微凶”直接翻成吉。八门按 **月令旺相休囚死×被宫生／宫迫／门破／生宫／比和25格** 取能量，宫迫与门破名称不互换； **天盘所有实际携干＋地盘干** 按 **落宫全十二长生分组×与月令有向关系25格** 各查，不以普通干旺相替代。若真实落宫二支归不同档且源择支法未核，两个候选全保留并标待核。
5. **天地盘格局和特殊条件**：逐宫检验已保存的 **81组天地干有序格局**（天盘干＋地盘干＋星及原书出处），记录有命中及原文吉凶、限制、反证、未落实的原书条件；不能把只命中格局名称当作吉凶已验证。逐宫取旬空、马星、天盘/地盘入墓、击刑、宫迫/门破等事实。**假空**：宫真逢空且**宫五行受月令生或比和**，或 **马星在实际对宫所临地支六冲空宫相应地支**，满足任一即假空；其他逢空为**真空**，不空独立标。此真假定义是用户本轮候选规则，尚待两书新独立案例验证；不把几何“对角”随意等同六冲。
6. **各用神与病宫关系一组一判**：天心、天盘乙、患者、时干、若有年命、乾坤辅助分别记录对天芮病宫的真实宫位 **克／被克／生／被生／比和／同宫**。确有本方克病宫时只用选中的两个**首层用神最终强度**查 **一张** 200格套件里的实际可用克制表：普通、施力假空、受力假空、施力真空、受力真空，各表25格；若病宫克本宫，应把**病宫作为实际施力方**查一次，不反向解释表格；双宫均空无用户组合规则即待核。非克关系不准套克制表，依该专题作者来源对生扶/受克/同宫解释。空亡影响的克制须真实应用角色方向，不能再进行第二次宫力比拼。
7. **凶吉证据合断**：先从每组宫内星、神、门、干、格局与本组病宫实际生克推定**本组吉／凶／待核**，并保留理由、反证、格局作用条件。**同一真实施力／受力宫对只作为一条独立关系证据**，不能因为天心+乙同宫就算两个胜负票；四吉神和门干补充同宫推理，不机械各算一票。五不遇时若命中单独作为一条全局不利证据；伏吟反吟仅缓急。有效吉组较多才偏吉，凶组较多才偏凶，同数或关键用神身份/反证未核则**吉凶待核**；不要用概率、健康分、V4.2计分或算票直接推真实死亡率。
8. **最后一定给一句结论**：列明确**古籍象意偏吉、偏凶或暂不能定**及原因，顺带说明缓急是伏吟慢／反吟快／均未触发，未具具体应期则不造日期。正式临床严重程度必须由医生检查，不用术数结论决定就医或用药。

> 起盘（四柱）、（阴／阳遁）（局），（五不遇时／非五不遇时），（伏吟主慢／反吟主快／星门缓急并见／不据此定缓急）。
>
> **天芮病宫**落（宫），病星（月令与宫关系、力量）；同宫（其他星力量）、（神名、五行关系、增强／减弱、微吉微凶）、（门名及力量），天地盘（天干力量、地干力量、已核吉凶格／待核），（空亡真假与原因、马、墓、刑、迫）；病象（已核证据链）。
>
> **天心医生**落（宫），星（力量）、神（趋向）、门（力量）、天地干（力量／吉凶格），（空马墓刑迫）；对病宫（真实生克方向、对应克制原格及一组吉凶／条件待核）。
>
> **乙奇医药**落（宫），（星神门干格与各力量及特殊条件）；对病宫（方向、实际克制原格／生克条件、吉凶）。
>
> **患者与事体**：患者用神（宫内能量组合及对病宫吉凶）；时干（宫内能量组合及对病宫吉凶）；年命（提供则含实际宫内组合及关系，否则不采用）；乾、坤（辅助宫组合和对病宫关系，不自造身份）。
>
> **综合断语**：（不重复的有效吉证多少）、（凶证多少）、（未核条件）；（吉多偏吉／凶多偏凶／证据相持待核）。缓急（伏吟慢／反吟快／均无），应期（只有确切书源条件齐备才写）。

每条原书天地干格局在审查结构中保留 `source_line_internal/source_sha256_internal`，用户简明文只显示格局名称、实证吉凶或待核条件；未经核实的书源谓词不可硬判。术数等级与神兽加减都是研究象意，不代表现代医学病情严重程度或治疗效果。
