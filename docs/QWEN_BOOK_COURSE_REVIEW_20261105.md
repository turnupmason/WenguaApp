## 下一版的课题和回答要求

1. 一个问题明确一个范围；人物、方位、五行、人体等分开问。条件题给出具体改变的条件，纠错题给出明确错误说法。不能只用“解说”“这段怎样理解”批量扩量。
2. 真实案例分开书中人物、来信者、原判断者、老师按语。先前判断、反馈后复盘、后续修正分别标记；原书错误作为明确的纠错材料，不能当正确正例。
3. 读盘、带资料整理、隐藏作者分析的推理分别训练和评测。完整独立断案须有完整事实、当时已知背景和可追踪的作者证据链；缺失不补造，后续反馈不得提前输入。
4. **先直接回答，再给必要依据；概念题通常 1–3 句，条件题保留成立条件和例外，案例按证据给分析和结论。** 不复述问题、不加固定开场/收尾、不重复句子。长句可换行，不能为简短删掉条件。这条已写入修订草稿；尚未重新训练到用户本地模型权重里。
5. 逐题语义审核、独立证据链评测与纠错题通过之后，另建新版本再训练。自动出处检查、低 loss、题量增加都不能替代专业审核。此次没有发布新训练就绪数据，更没有承诺百分百预测正确。

用户无需重抄书、重录 194 案或逐题替代研发审查。先修课程再决定训练组合；不继续靠扩大 rank、增加轮数重复训练已知有问题的课题。
