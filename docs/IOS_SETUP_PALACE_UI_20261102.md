## 已实现

1. 选领域后先显示居中准备卡，写明疾病健康／奇门论疾等实际方向、普通和预定事项说明、填写按钮及用户要求的完整30秒静心文字。删除自动onAppear弹窗；按钮进入同一导航内的填写页，返回准备页。
2. 表单改为一个有明确间距的容器，消除Group背景分发造成的碎白框。关系改为「问事人与自己的关系」；性别、出生年命、伤损、病程等标题显示在控件上方。未验收主题仅记录基本关系与称呼，不强求医学人物绑定。
3. mode由专题类型决定，不能切换；原生resolveForTopic也硬性校验。五列公历滚轮分别标年、月、日、时、分，年／月切换同步收敛月末；按所选IANA时区校验闰日、DST缺口与重复时刻。选择确认及最终起局都拒绝非未来时刻。普通问事只在完整静心后采集真正确认时间。
4. 坤二双列天／地干共享固定槽位，刑墓标记通过overlay叠加，保留红刑／橙墓，不参与字宽计算；不改天禽寄宫或干对次序。四柱年月日时标签在彩色干支下方，删除右侧时间；重复时间来源栏改为实际领域／专题方向。
5. 伤门证据与结论按sectionID分组；相关短句合成段落，增加伤损部位、星门神、星干信息、天地格、取象限制、主要结论、分宫旁证等标题。runs与paragraphs可严格拼接还原全部原文，存储、引擎断词和反证限制不变。
6. 宫位详情标题居中，移除本机Swift和本机实算标签；身份徽章字体由caption2改为16，盘中角色字由9改为12。
