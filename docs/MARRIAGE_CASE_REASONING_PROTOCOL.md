## 原书主要取用方法（第3–13行）

恋爱婚姻一般取天盘乙奇代表女方、天盘庚代表男方，比较两个所落宫位的相生、相克、比和、刑冲，综合吉门吉格；六合作媒人与婚姻象；乙庚两宫的星门神与特殊格局在书中对应男女形貌、职业、意愿。已婚者还要比较相合之干及双方实际年命落宫。丁奇在该作者方法中代表第三者女性，丙奇可能代表第三者男性。

**这些是来源中的传统条件与类象，不是现实关系事实鉴定。** 必须从问事领域、提问人与当事人关系及盘面事实选择证据，不能直接断言某人出轨，也不能把所有属性机械设为必然结果。案例二尤为重要：作者认为单看乙庚不能准确对应女儿的现实婚恋情况，进一步用男女年命、父母年干、时干与六合作判断。保留这种实际采用的替代取用路线。
