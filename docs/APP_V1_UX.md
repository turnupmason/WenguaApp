# 用户亲自提出的问卦流程（V0.1）

1. 首次打开：云雾、深色、水墨/金色动画，短暂介绍与上手指引；以后不强制重复引导。
2. 选择问事领域：先分专题，再进入具体子类；不得把所有领域笼统套同一用神。
3. 选择与事情的关系：本人、帮朋友、帮父母、父母帮孩子、其他。区分操作人和实际当事人。
4. 静心倒计时：提示闭上眼睛，心中默想事情约一分钟；结束时**捕获此刻设备本地时间与时区**。文化仪式不是证明真实预测有效性的因素。
5. 经原书和案例核验的起盘模块→已审核规则匹配→九宫与断案依据→最后一句醒目的条件化总结。
6. 首次提交的交互原型仅演示流程：因为起盘、方法、断词尚未验收，最终画面必须清楚显示“尚不可给出正式解读”，而不是编造“吉、凶”。

App 预计能够作为本地离线静态 PWA 首先验证体验；将来再选择 iOS/Android 原生封装方案与本地 SQLite。
