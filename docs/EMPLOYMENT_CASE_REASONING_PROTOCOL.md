## 第一节：传统取用规则与跨章联用

1. 开门代表文职工作、职位及单位；杜门代表武职、军警保密单位。工作种类必须根据求测背景确定，不将一个特定案例绑定的“开门=外交部/生门=外经部”扩张为所有公司或部门。
2. 年干代表较高上级、值符代表直属顶头上司、月干同事或同行竞争者、日干是问测本人、时干通常是下级或员工，但案例二**母亲代问儿子工作**具体用时干庚兼儿子年命甲寅癸；不能机械把母亲的日干乙当成儿子。
3. 自身日干或年命、宫位时令旺相休囚、吉凶门格神、开门杜门与求测人相生克共同判断求职、晋升、降职或退休。原书同时明讲：**个人宫克开门也不必然失败，努力后仍可能成功**。因此不允许一个凶格直接覆盖多组反证。
4. 晋升看天时、地利、人和、自身条件以及年干/值符/开门；开门杜门克用神、太岁值符月时干克本人、反吟空亡入墓等仅是原书传统类象，不能在真实就业情境中确定有人违法、告密、必被革职。
5. 开门遇九星作传统人格标签，原书对天蓬/天芮/天柱等存在负面“善恶”用语。这是书中人物象意、**不是雇佣、招聘或真实个人人格评估依据**。
6. 退役以杜门、日干及反吟、伏吟、螣蛇等条件综合。必须与普通就业和毕业分配分开，不能将军队退伍规则套到所有求职。
7. `data/knowledge/shenqi/employment_prediction_ch05/method_index.json` 已把以上及案例特有用法整理为 **53条 `draft_source_traditional` 候选**，每条带原书行号与跨章 `concept_id/ref_concept_id`，并有8阶段完整一次性作者式解读流程；未经客观预测精度或业务审核。
