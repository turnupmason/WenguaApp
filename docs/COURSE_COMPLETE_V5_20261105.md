四格式：基础 2,790；条件 436；原表与应用读取 4,161；完整案例及分步复盘 3,809。类别是课程组织方式，不意味着每条“条件”题都是多轮，或每条复盘都是从未见过的整盘预测。

9,532 个核心任务在训练侧，895 测试、769 验证；多轮拆监督后实际训练 9,542 行。通用知识允许训练；原案固定留出家族及跨书复述不回灌训练。复盘比较可能含已知通则，不能把这些分数解释为全新独立事实预测的准确率。

## 语义处理

- 保留前提、主客方向、条件与例外；九遁的“且/或”、成事与败事应期、宫数与时间单位分别处理。
- 十干长生、九星旺衰、三刑名称和方向等两书异说分来源；没有强行统一。
- 普通正文与九宫表相邻时分别处理，不能整段跟随表格跳过。
- 案例区分原叙述、明确老师按语、学生误断、后来披露与反馈。索引没有收全的老师评论另补。
- 错断案例保留原段和核对说明，不能把学生观点或事后改释当作原始正确结论。通则章节里的案例转述也保留相同边界。
- 正文定位引文 6,003 份逐一回查章节 SHA 和坐标；1,611 份 SQL 原抄盘单独标记，不能冒称重新核过纸本图片。
- 不加入旧人工评分或无依据百分比。书中自身的吉凶断语仍按原书来源保留。

不能承诺“百分百完全完美”。可验收的是指定材料均有去向、条件有保留、原文可追溯和检查没有静默漏项。未提供的纸本页不能冒充已核对；“日奇人/入天罗”字形、作者的待实践假说和不同语境命名保留明确疑点。模型是否真正会用，仍须看留出实答。

## Windows 启动

正在运行的 V4 继续完成。V4 源码、数据包、运行哈希、参数、检查点均不改；不要把 V4 检查点传入 V5。

PowerShell：

```powershell
Set-Location "$env:USERPROFILE\WenguaApp"
git pull --ff-only origin main
.\local\qwen_env\Scripts\python.exe -X utf8 unlock_course_v5.py
```

输入此前 V4 的私有密钥，恢复到 Downloads；不必通过网页下载工作区附件。先检查教材：

```powershell
.\local\qwen_env\Scripts\python.exe -X utf8 run_course_v5.py check
```

V4 结束后再运行：

```powershell
.\train_wengua_v5.cmd
```

输出 `local/course_v5/run1`；官方固定 8B 基模、新适配器、4096、r8/r16 注意力四投影，最多 6 个不同正式配置。先做真实长度 100 更新压力测试，保留显存失败原因；再按验证结果选择结构、学习率、dropout/预热。每组 3 个连续 epoch，优化器不逐轮重建，保存完整检查点；选出一组后才做最终测试。默认最长 168 小时是运行上限，不是预计耗时或必须跑满的训练量。

同组中断重复同一命令恢复；需要显式检查点可传 `--resume-from-checkpoint`，源码、参数或教材合同不同时拒绝恢复。不要用无限重复训练代替检查回答质量。
