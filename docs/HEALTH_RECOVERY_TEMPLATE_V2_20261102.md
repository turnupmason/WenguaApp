## 使用顺序与边界

沿用既有疾病判断及真实患者绑定 → 明确时程、缓急与单位 → 选定本次恢复所需的实际应期对象 → 检查空马墓刑冲合生旺及其例外 → 先支后干并核时限 → 经历法计算后填写病愈候选期。

资料L48要求先判疾病能愈，再取成功类应期；吉凶净分不能直接换算康复天数。已有病情结论若不足以确定恢复前提，应当补核这一前提，不重新输出一份强弱／病位报告。

资料包含年、月、日、时；现有历法区间生产器仅日、月。其余粒度与新触发法仍须实现验证，不为了给日期而擅自把年／时换成月／日。

仅在确有适用依据时才填写符使、同气、干支和有效时限段落；未知不填，冲突不任意取最近。
