# WenguaApp · 恋爱婚姻22场景：六层全要素用神与作者证据研究流程 V1.3

## 版本边界
这是用户提出的22个重要细场景的**研究级方法总谱**，而非22条一看符号就“锁死结果”的定论。每个场景都从数据库已有的九个婚姻问事完整流程继承8步古籍取用逻辑、作者证据链和独立验证/反证标签。在其中对用神候选、刑冲墓迫空马、不同人物和具体应期做细化。两个经典两书一共43来源章节、194个整案；其中婚姻领域旧有14个关联家族，**不等于22个不同场景都有作者独立实战确认**。

根 `AGENTS.md` 和 `prompts/global_six_layer_reasoning_v1_3.md` 对**所有领域**强制六层，不只是婚姻。机器数据 `data/knowledge/phrase_library/marriage_v1_3/twenty_two_scene_methods.json`；数据库迁移 `schema/migrations/041_global_six_layers_marriage22_scenarios.sql`。完整版V1.3仍保留旧194案、九套旧婚姻问事流程、四条语言原型；当前没有经过全盘+历法验证的可发布具体占断。以下每条原书引用必须区分首断与回访，原书来源不等于现代心理、医学、法律的事实证明。

**第三层 · 六亲用神与问事绑定**：先确定谁是问者、谁是对象，按实际关系确定主辅用神。本场景候选坐标：本人日干/年命、对方由已知角色和年命绑定；六合仅婚缘辅证

## 人物、真实安全和应期共同边界
- **实际对象优先于“男庚/女乙”的模板**：问同性、代测父母子女、未知对方性别或两名不同问者时，必须按人物与年命重选主辅，不强制单一月干/时干公式。
- **不诊断不指控**：玄武、螣蛇、天蓬、天芮、墓、击刑、丁丙、值符等不能单凭古籍象意“实锤”家暴、出轨、性病、诈骗、某人的性倾向或法律胜诉。用户需要具体断卦，系统可以对盘面象意给传统倾向，但不能假扮现实外部事实证据。
- **门迫按真实五行规则**：门迫是门五行克落宫五行；用户举“杜门落震宫”相同木，不能套门迫结论。六合是八神不等于门，只有其落宫所临八门与宫位发生具体门克宫时才记门迫。
- **事件目标需要拆解**：表白成功≠成情侣，复合≠复婚登记，订婚≠领证≠办婚礼，异地见面≠异地关系维持，离婚≠法院判离≠财产判分≠抚养安排。每件要分别计算应期，不能沿用书例日期给新盘。
- **完整执行 vs 准确率**：全盘24项、六层、原书来源、结果/应期、GPT语言都是强制步骤，仍须持续用真实经确认原盘和未见历史家庭测试其鲁棒性、不能宣称古籍预测能100%准确。未知必须列出具体缺失，不编造日期。
