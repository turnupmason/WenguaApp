## 唯一准入依据

允许：两书可定位原文；书中的完整领域取用流程、条件、例外；原书九宫原抄；作者明确的分析步骤、断语、修正与分栏保存的后来反馈。书中的“大吉”“凶”等原话按其条件保留。

禁止：人工打分表、旧程序的力量／吉凶档位与合成判词、AI自行补出的规则、无古籍出处的人物配置、用户笔记和总结（即便此前已认可）、把后验反馈塞入事前问题，以及把复制问法当新证据。排盘计算只可提供已验证的盘面事实，不能提供模型必须照抄的吉凶答案。

`src/wengua/qwen_source_policy_v3.py` 做保守来源准入：每条引用必须落到两书定位记录；原抄宫格另与原SQLite行逐字段连接核验。来源准入不是回答正确性认证。根据分层来源排除，而不是用“吉凶”关键词删原书。
