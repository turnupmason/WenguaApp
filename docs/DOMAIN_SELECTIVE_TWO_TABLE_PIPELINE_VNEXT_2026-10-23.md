# 问卦 V-next：先按专题取用，再用两张硬编码表判断能量与对抗

2026-10-23 最新用户澄清；适用于现有 WenguaApp 的**研究 V-next**，不改变已经冻结的原生起盘、V3.9.1 正式文字以及历史事件数据库。

## 固定顺序：起盘 → 专题选用 → 表一 → 表二 → 证据合断

1. 时家转盘：根据真实时辰、历法与已验起盘方法，一次得到完整九宫图。这一步包含每宫星、门、神、天地干等**原始盘面事实**，但**不等于必须将所有符号计算为需要断事的用神**。
2. 专题＋细分类别：由**领域**和**具体断事类型**定位可执行的原书用神模板。当前实现的是 `("health","severity")`，其它领域待逐章核实角色绑定和专属胜负解释后另建模板；绝不能把疾病取用直接套到婚姻/工作/求财。
3. 当次相关人物：`bind_patient` 先根据本人/父母/夫妻/子女/其他关系确定真实患者用神。疾病当前最小集合：天芮、天心、乙（天干）、患者用神、时干；有**真实合法且能落宫的出生年干支**才增加患者年命；病人男性才加乾六宫、女性才加坤二宫；性别未知**不强制计算乾坤**。原书确实额外绑定的其他辅助宫才能增加；同宫多角色要共享实际事实，不多计票。
4. **第一张硬编码表（单因素能量）**：`src/wengua/factor_energy_25_rules.py` / `src/wengua/selected_duel_table_vnext.py:table_one`。调用当前被选中的*关键*星／门／干、其真实落宫、当月节令。符号本身的月令五态（九星旺相休囚废；干门旺相休囚死）×相对落宫主四类关系＝20种预设候选，实际第五种「符号克宫」另有保真分支。输出极大／大／中等／小／极小。八神自身不按月令五态，值符属土；**只有当领域原书适用条件需要这个八神时才查表**。另算**实际落宫自己**的月令旺弱、旬空、入墓、门迫、击刑、十二长生（尤其乙奇的天干条件）。不用对一个选中宫内所有星门神天地干都自动查完20格。
5. **第二张硬编码表（两个因素对抗）**：`src/wengua/selected_duel_table_vnext.py`。本方符号五档×对方五档是5×5预设比较表；本方落宫五档×对方落宫五档是第二张5×5比较，最后按3×3固定综合表，结合两个**真实宫位生克方向**和空墓刑迫，给传统候选能／不能／艰难／条件待核／不适用。**这两套判定属于同一张「双因素对抗表」的子索引**；不依赖所有星×所有门×所有干预先物化成海量字典。只有「克」或「生」等明确关系才谈作用，“同宫”不伪造克；分强弱时双方自身和双方宫位都要看。
6. **专题规定需要对抗谁**：疾病模板只计算 `天心→天芮`、`天心→患者`、`乙→天芮`、`乙→患者`、`患者→天芮`、`天芮→患者`、`时干→天芮/患者`、存在年命时 `年命→天芮/患者`、有性别身份时 `对应乾或坤→天芮/患者`；真实有条件的原书辅助宫才依模板增边。**未选宫位不查表，不生成对抗，也不导出图的笛卡尔积。**
7. 领域内吉凶取向取决于**角色和方向**，不能只看能量高低。例如天心或乙对病星有效相克可归传统有利候选；病宫有效克患者宫是不利候选。同一真实两宫物理关系只计一次，未知／艰难／阻挡明确作为待定；天芮原25象意仍独立留一条复合证据。按**去重后的吉象、不利象、待定象**形成研究性倾向，角色取用或原书条件不足时返回不确定；应期依原书实际地支触发判，不按凶吉条数瞎造日期。原强度五档尚未以两书独立完整案例校准，不能暗示临床可靠、指导药量。

## 代码与数据接口

- `src/wengua/domain_selected_energy_vnext.py`: `DOMAIN_CASE_TEMPLATES`、`HEALTH_EDGES`、`HEALTH_POLARITY`、`selected_health_sequence`、`selected_health_sections`。先选择，用 `one_cache` 缓存同宫同角色强弱事实，原始 chart 已含全九宫，但只枚举必要角色。
- `src/wengua/selected_duel_table_vnext.py`: 表一复用固定矩阵；表二 `STRONG_WEAK_5X5` 和 `DUEL_OUTCOMES_3X3` 组成常量，真正执行 `matchup` 时只查两个已经选定因素。禁止运行时临时生成整张400/1600/10000交叉表。
- `src/wengua/health_palace_sequence_vnext.py`: 默认走 selected 路线。曾经验证并归档的 `health_full_role_network_vnext.py` 只通过 `inquiry["_research_full_graph"]=True` 进入，明确**研究级调试／旧回归入口**，不得冒充 App 每次断案运行逻辑；保留其源文件、全部历史失败CI和旧断词，不予删除或覆盖。
- V-next `full_health_role_strength_network` DTO 字段现在默认保存**选中的** `nodes`、`directed_edges`、`table_one_queries`、`table_two_queries`、`inspected_palace_ids`、`precomputed_cartesian_pairs_materialized=False`。旧调试路径结构另存，不强要求两者字节相同。
- `tests/test_domain_selected_energy_vnext.py` 检查双表、实际相克两侧、男性乾／女性坤／性别未知不选、真实年命可选、不可选宫不算、用神对抗条数边界、天芮25格单证据与研究候选吉凶汇总；`tests/test_health_full_role_network_vnext.py` 仍用显式旧研究标志检查历史完整网络，不破坏以往失败记录。

## 约束

仅对已由原书授权的具体专题选用套模板；现有 `("health","severity")` 为 V-next 候选。**先精确取用神才有权调用两张表**。原来用户要求完整九宫图是起盘事实，不等于需要全宫对抗计算；性别不明不计算两个性别宫；没有年命不计算年命；每条被选择关系结果须能回溯两个盘面符号与宫位事实。保留 43章/194古籍案例、81古籍天地干、42疾病补充、17复合、冻结 V3.9.1、弃用 V4.2 和 iOS 原生已核九宫。
