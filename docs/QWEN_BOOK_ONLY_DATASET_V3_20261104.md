核心任务由实际切入点构成；百万扩写是这些任务的语义同义改问和有限表达模板组合，**不是百万条独立规则、独立病例或全新推理题**。这只是候选池规模，不是模型合格门槛。每条带core_id、来源、固定分组和1/该核心变体数的core_weight，避免多换问法就给同一知识更多训练权重；实际训练还应按事件家族、任务类型采样，而不是机械反复遍历全部变体。

原盘应用细分：1,435条原抄星字位置读取、295条作者已写依据→随后原文判断补全、713条原文辅助的作者证据组织、430条案例条件分析。没有为新造盘编作者结论。完整案例包括191例作者全案教学和25例有明确初问／初断记录的阶段视图；前者提供作者资料用于学习，不冒充隐藏作者分析的新盘盲测。194案全部保留，3案缺逐段作者分析时不补造。

## 纯书源边界

- 原库SHA256固定为21362e6f0266c03dcdc4a7ef35f45954ba274ae6458de0ba341132abca7d0405；43章原文哈希核对，1008作者原段逐字保留。
- 标准答案只来自可定位原文或原书宫格转录。把原书完整句子排成短段落，逗号连接的条件不拆散；原文的吉凶词保留，不按关键词删除。
- 原案登记字段有些是编辑摘要。不能定位的字段不冒充作者原话；可定位的判断片段分别保留。原始库始终不改写。
- 来源坐标索引只包含原案ID和行范围，用于区分一般方法／案例范围以及同案分组，不提供人物规则或判词。
- later_feedback、后续披露和初问分开。明确初问视图只含已标为初问的原文和原抄盘，不直接复制known_before。
- 所有同案、同出处及其变体固定在同一分组；程序仅核对出处与事实一致性，不用旧分数判定新模型对错。

## 可复现入口

新构建器只依赖Python标准库，完全独立于旧课程运行入口：

```bash
python -m scripts.qwen_book_dataset \
  --source-db archives/sqlite/WenguaApp_双书194案例_V391纯断词十二长生_完整研究库.sqlite3 \
  --case-source-coordinates data/knowledge/qwen_book_only_v3/case_source_coordinates_20261104.json \
  --output local/qwen_book_only_v3_new_run \
  --pool-size 1000000 --materialize
```

这是数据生成命令，不能启动训练。生成目录必须是新目录；已有材料保持不动。来源定位、后验隔离、同组划分、自然回答、旧教师隔离和多轮监督视图均有专项测试。


纯古籍四格式构建器实测：完整1028 tests、0失败／0错误、3既有skip；新增11项覆盖原文定位、条件不截断、作者依据补全、初问反馈隔离、四格式、同案分组、登记摘要不冒充原话、任务改问、独立split文件和多轮监督目标。实际百万逐条回读／43章哈希／1008作者原字一致的审计与token长度统计另有记录，不能把软件通过当已证明独立断案能力。远端CI须按本次源码提交核验。
