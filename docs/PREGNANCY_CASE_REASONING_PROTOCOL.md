- **例2**：原作者明确胎儿性别拿不准；从对冲宫干起初想到11月19日，随后**已经听到医院11月21日预产期**，再用另一应期方法选择11月21日。案例整体书内判对，方法中的“有外部提示”不能在初始预测模拟中隐瞒。
